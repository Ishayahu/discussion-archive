# Архив интеллектуальных обсуждений

Канонический исходник публичного архива обсуждений Ишаяу.

Публичная витрина на AppDeploy: https://app-yspti2.v2.appdeploy.ai/

## Структура

- `index.html` — главная страница архива
- `politics.html` — политические обсуждения
- `debate1.html`, `debate2.html` — два адверсариальных аудита
- `philosophy.html` — философские обсуждения
- `selfhood.html` — обсуждение «Где находится „я“?»
- `src/styles.css` — общий стиль
- `vite.config.ts` — multipage-конфигурация Vite

## Важное правило публикации

Каждая отдельная HTML-страница, которая должна открываться по прямой ссылке, должна быть перечислена в `build.rollupOptions.input` файла `vite.config.ts`. Простого наличия HTML-файла в исходниках недостаточно: иначе Vite не включит его в production build и AppDeploy может вернуть `AccessDenied`.

Канонический порядок изменений: GitHub → AppDeploy. AppDeploy рассматривается как публикационный слой, а не единственное хранилище данных.
